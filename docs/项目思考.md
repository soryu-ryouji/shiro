# shiro 项目思考

shiro 是面向剧本创作的工具

- 剧本编辑器
  - 提供剧本项目的 markdown 编辑功能
- 剧本阅读器
  - 模拟在手机上的屏幕尺寸
  - 模拟在电脑上的屏幕尺寸
- 内容库
  - 存储当前的写作规范
  - 存储各平台各题材剧本的基底套路
  - 存储故事推进模式
  - 存储基础人物库
- 工具
  - 自动取作品名
  - 自动取人名
  - 自动拆解
- 模型
  - 适配各模型的接入

## 使用形态

- 本地使用为主，支持联网（下载剧本模型等资料、调用模型 API）
- 数据量主要取决于本地资料（如从网络下载的剧本模型等）
- 支持 Windows、macOS、Linux
- 局域网内的设备（iPad、手机等）可通过浏览器直接访问编辑器，脱离电脑编辑内容
