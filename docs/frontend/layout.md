## Database（内容库）

侧栏分两组：

- **元数据**：角色（全局人物库，接内容库资产 API）；后续世界观等资产类型在此扩展
- **内容库**：写作规范 / 基底套路 / 推进模式（占位，后续改为外部导入方式实现）

选中「角色」后中栏分两列：左侧角色卡列表，右侧选中角色的详情（frontmatter 字段做徽标 + 正文 markdown 渲染）。

- 数据源：`~/.config/shiro/db/人物/<id>.md`，明文 markdown + YAML frontmatter，格式见 [资产格式](../asset-format.md)
- 宽容解析：未标记 `shiro_asset: character` 或 frontmatter 损坏的文件不进列表，按普通文档对待
- 列表首次进入拉取，之后沿用缓存；列表头提供手动刷新（库在 shiro 外被编辑后同步）
- 空态提示库目录位置与格式文档入口

**筛选**（列表头下方）：

- 文本搜索：匹配名字 / 原型 / 标签 / 功能角色 / 来源（客户端过滤）
- 功能角色胶囊：从列表数据提取去重，点击筛选、再点取消

**新建与编辑**：

- 列表头 + 按钮新建：输入显示名生成骨架卡（四节预置标题），同名自动追加 -2/-3 序号；纯中文名回退 `character-<时间戳>` id
- 详情头铅笔按钮进入编辑态：原文编辑（markdown + frontmatter），保存走原子写（临时文件 + rename）
- 保存后重新解析反馈：frontmatter 损坏/未标记类型时内容仍保存，但顶部横幅提示该卡会从列表消失，编辑器保持打开供修复

## 手机预览

写作模式顶栏（编辑区右上角）提供「手机预览」按钮（有打开的文稿时可用）：

- 点击弹出 390×844（随窗口高度收缩）的手机预览浮层，把当前文稿渲染成手机阅读视图
- 内容与编辑器实时同步（含未保存输入），边写边看
- 排版沿用外观设置：正文字体/字号、行距、段距、分段方式（回车分段时每行独立成段）
- 遮罩点击或 Esc 关闭

后续演进方向：模拟更多目标平台（电脑屏幕、特定平台客户端）的阅读体验。

## 滚动条

全局采用自绘覆盖滚动条（VSCode/Ulysses 式，不占布局、无轨道无按钮）：

- 常态隐藏；滚动中显现 8px 半透明胶囊滑块，停止滚动约 0.9s 后淡出（DOM 元素支持 transition，原生滚动条伪元素做不到淡出动画）；滑块可拖拽，悬停/拖拽时加深
- 实现：`utils/overlayScrollbar.ts` 的 `attachOverlayScrollbar(el)` 隐藏原生条，向容器注入绝对定位的滑块元素，滚动时用 translate 补偿滚动偏移把滑块钉在视口边缘，ResizeObserver 跟踪容器尺寸
- 接入方式：模板滚动容器挂 `v-overlay-scrollbar` 指令（全局注册）；CodeMirror 的 `.cm-scroller` 由 Editor.vue 命令式挂载
- 未挂载的容器（如 v-html 生成的 pre）退化到 `style.css` 的原生细胶囊兜底样式；标签栏维持隐藏滚动条不动
