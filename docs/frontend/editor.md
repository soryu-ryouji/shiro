# 正文编辑器

CodeMirror 6 + 自研实时预览（`src/utils/livePreview.ts`），Obsidian 式：光标不在处渲染格式并隐藏语法记号，光标所在处显示原文可编辑。内容始终是纯 markdown 文本，编辑器只做渲染与文本变换，不引入专有格式。

文稿格式两类：markdown（.md/.markdown）与纯文本（.txt，见 `src/utils/sheet.ts`）。`.txt` 走纯文本模式：不装 markdown 语法/实时预览/表格挂件扩展，底部工具栏隐藏标记按钮，大纲恒为空；只保留纯编辑、段间距、字数与自动保存。预览浮层对 .txt 按原样纯文本显示（不解析标记）。

## 实时预览范围

- 标题：`#` 记号以挂件挂在内容列左缘留白（Ulysses 式），只加粗不改字号
- 引用：`>` 记号隐藏，行内细竖线贴文本左缘
- 无序列表符号渲染为圆点；有序列表保持原样
- 粗体、斜体、删除线、行内码
- 代码围栏整行染色，内部无语法高亮
- 有意从简（v1）：不解析嵌套/跨行标记、不支持转义

## 表格编辑

`src/utils/tableView.ts`，Obsidian 式就地编辑：

- 表格在编辑区**始终渲染为真 `<table>` 挂件**（块级 replace 装饰，吃满正文列宽——新增列只是把宽度重新分配给各列；空单元格渲染 `<br>` 撑出行高），没有「源码态」；支持对齐语法（`:-` / `:-:` / `-:`）
- **点击单元格就地编辑**（contenteditable），输入即时同步回 markdown 文本；输入法组合期间不同步，上屏后一次性写入；粘贴的多行内容折叠为空格（单元格不含换行）；单元格内的 `|` 以 `\|` 转义写回、解析时解码
- **键盘**：Tab / Shift+Tab 按行主序跨格；Enter / 方向键上下跨行；末格 Tab/Enter/下方向键追加新行；左右方向键在单元格文本边缘时跨格；Escape 退出表格（光标落到表格后）；Cmd/Ctrl+Z / Shift+Z 走文档撤销/重做
- **结构操作**：右键菜单与行/列手柄（点击弹菜单，手柄跟随活动单元格）支持在上下/左右插入行列、上下/左右移动行列、删除行列、设置左/中/右对齐；悬停或编辑表格时，下缘/右上角「+」按钮追加行/列；菜单复用 `ContextMenu.vue`（挂件在 Vue 树外，经 `CustomEvent` 桥接）
- **自动对齐**：光标离开表格时按列显示宽度（CJK/全角按 2）重排管道；输入过程绝不重排（IME 安全），重排可撤销
- **工具栏**：「表格」按钮插入 3 列模板并直接进入首个表头单元格编辑（光标在表内时插到该表之后）
- 实现有冒烟测试：`node tools/test-tableview.mjs`（esbuild 打包后在 node 直跑解析/渲染/结构变换断言）；DOM 级集成测试：`node tools/test-table-electron.mjs`（真实 Chromium/Electron 里跑插入/输入/转义/跳格/菜单/退出全链路）

实现分层：解析（纯函数）→ 网格模型（gridOf/renderGrid 与结构变换，纯函数）→ 控制器（`tableController` ViewPlugin，持有组合状态等全部编辑状态，自动对齐也在其中）→ 挂件（纯渲染，事件全部委托给控制器）。**表格的块级装饰由 StateField（`tableField`）经 `EditorView.decorations` 提供**——CM 不允许 ViewPlugin 以函数形式提供块级装饰（否则 dispatch 时抛 `Block decorations may not be specified via plugins`）。扫描结果按文档 `Text` 实例用 WeakMap 缓存，同一份文档多处消费只扫一遍；挂件 DOM 复用时其监听器属于旧实例，块位置可能过期，所有操作先经 `resolve()` 按原文/选区重新定位。活动单元格由编辑器选区推导（选区藏在 replace 装饰内，含光标偏移/全选意图），装饰重建后状态可复算；挂件 eq 忽略活动单元格文本与光标意图，保证输入中 DOM 复用不丢光标；焦点由控制器在 dispatch 后同步落进目标格（不等挂件微任务，避免与 CM 的 DOM 选区同步竞争）。

v1 已知取舍：不支持引用/列表内嵌表格；行列移动走菜单不支持拖拽；表格后紧跟的含 `|` 段落行会被吸入表格（空行可截断）。

## 底部工具栏（Ulysses 式）

块级标记按钮（标题/加粗/列表/引用/表格）居中；字数（有选中时为「选中 / 总数」）与保存失败提示在右端。标题连点在一至四级间循环；加粗无选区时作用于整行；列表/引用对选区覆盖的行做行首标记切换。纯文本（.txt）文稿隐藏标记按钮，只留字数状态。字数口径可在设置「通用」页切换（仅中文字符 / 中文字符与标点），切换后状态栏即时重算；策略表在 `src/utils/wordcount.ts`（选中字数同口径）。

## 其他

- 自动保存：输入防抖 800ms，切换文稿/卸载前 flush；磁盘外部变动经 daemon 监听推送重载（有未保存内容时本地优先）
- 大纲：文档标题列表，点击跳转、当前章节高亮。显示时作为布局内右侧面板**把正文往左挤**（不遮挡文字）；三态由顶栏按钮循环切换（自动 = 编辑器宽度 ≥1040px 时显示 / 开启 / 关闭，`outlineMode` 持久化在 localStorage）。编辑器自绘滚动条钉在**主区域右缘**（大纲面板右侧）——滑块挂载到不滚动的主区域容器（`attachOverlayScrollbar(el, host)`），大纲属于编辑区域而非独立区块
- 正文宽度：设置面板「正文宽度」（px，默认 760）是正文列的**宽度上限**（max-width），空间不足（如大纲展开挤压）时自动收窄；驱动 `--editor-content-width`，正文列与底部工具栏分隔线同步
- 预览排版：手机预览的行距/段距/首行缩进是独立设置（`--preview-line-height` / `--preview-para-gap` / `previewFirstLineIndent`），不跟随编辑器排版——阅读偏好与写作偏好分开
- 段间距：按「分段方式」设置（回车分段/空行分段）只加在新段落首行；表格行不参与分段，保持紧凑
