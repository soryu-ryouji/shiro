# 存储设计

## 全局目录

```text
~/.config/shiro/
├── db/                 <- 内容库（写作规范、套路、推进模式、人物库）
├── config.toml         <- 配置：局域网 key、模型 provider 与密钥
├── history.toml        <- 打开过的项目记录（路径、最近打开时间），供启动页/最近列表使用
```

Electron 自身的缓存留在默认位置，shiro 自己的数据全部收敛在上述目录。

`db/` 不是数据库：内容库全部以文本等明文文件存储（TOML/Markdown），可直接查看、手动编辑、版本管理，叫 `db` 只是为了理解方便。库按类别分目录（规范/套路/推进模式/人物库），条目形态与目录内部组织在实现期细化。

`db/` 中的人物库等属于**全局资产**（跨项目复用的素材库），与项目文件夹内的**项目资产**相对；两者的引用语义（应用到项目即复制实例化、不做活链接）见 [AI写作工具制作思考](../AI写作工具制作思考.md)。

## 剧本项目：真实文件夹

剧本编辑器类似 VSCode 打开项目文件夹：用户选择文件系统上任意位置的文件夹，shiro 直接对照该文件夹工作。新建项目（`POST /api/v1/projects`，body：`{path, name?}`）即选一个已有文件夹登记为项目，不检查、不改动文件夹内容，只补齐缺失的 `.shiro/` 元数据并写入 history 记录。项目显示名独立于文件夹名：来自 `.shiro/project.toml` 的 `name`（缺失/为空时回退文件夹名），创建时填写的项目名即写入此字段；重命名文件夹不影响显示名。

- 正文就是文件夹里的真实文件（markdown 或纯文本 .txt），daemon 直接读写，不复制、不另存副本，文件夹是唯一权威数据源
- 文件在 shiro 外被修改（其他编辑器、同步盘）时，daemon 监听文件变化并同步到界面
- 项目级元数据放项目文件夹内的 `.shiro/` 隐藏目录，同 VSCode 的 `.vscode/`，随文件夹一起走

推荐的项目目录结构：

```text
剧本项目/
├── .shiro/              <- 项目元数据（shiro 专用，隐藏）
│   ├── project.toml     <- 项目信息（书名、题材、平台、进度）、章节根目录等配置
│   ├── backups/         <- 定时快照（zip，轮转保留）
│   └── trash/           <- 回收站（删除的非空目录移入此处，可手动恢复）
├── 正文/                 <- 章节根目录，一章一个 .md，推荐「序号 标题.md」命名
│   ├── 第一卷/
│   │   ├── 001 序章.md
│   │   └── 002 启程.md
│   └── 第二卷/
├── 大纲/                <- 总纲、卷纲、章纲
├── 设定/                <- 人物卡、世界观等
│   └── 人物/
└── 参考/                <- 编剧自己的项目文件
```

语义边界：

- 除 `.shiro/` 外的一切文件与子目录，shiro 都原样展示、原样读写，不干涉用户的组织方式——`正文/`、`大纲/` 等只是推荐约定，不是强制结构
- 章节根目录默认 `正文/`，可在 `project.toml` 调整；章节顺序默认按文件名排序（序号前缀），需要手动调整时记入 `.shiro/`

## 备份与快照

不做云同步，丢稿的兜底在本地：

- **原子写入**：自动保存先写同目录临时文件再 rename 覆盖，写入中断（断电、崩溃）不会腐蚀已有正文
- **定时快照**：daemon 对打开的项目定时打快照（有变更才生成），整个项目文件夹打成 zip（含 `.shiro/`，排除 `backups/` 自身），存项目内 `.shiro/backups/`，保留最近 N 份轮转删除——快照随项目文件夹走，拷走文件夹即带走全部历史
- 快照间隔与保留份数可在设置中调整，具体参数实现期定
- 项目文件夹放同步盘时，`.shiro/backups/` 会随同步膨胀，不想同步可在同步盘客户端中排除该目录

## 同步与版本管理

全部数据为明文文本，天然适合同步盘与 git：

| 内容 | 位置 | 说明 |
| ---- | ---- | ---- |
| 剧本正文与 `.shiro/` | 用户项目文件夹 | 随文件夹同步/进版本管理；`backups/` 可在同步盘客户端排除 |
| `db/` 内容库 | 全局目录 | 明文文件，可同步、可手动编辑 |
| `config.toml` | 全局目录 | 含密钥，仅本机，不要同步 |
| `history.toml` | 全局目录 | 本机打开记录，无需同步（记录的是本机路径） |
